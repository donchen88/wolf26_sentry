        # 网线直连快速配置指南

## 一、准备工作

1. **准备网线**：使用普通网线即可（现代网卡支持自动翻转）
2. **确定IP地址**：
   - 导航主机：`192.168.1.10`
   - 自瞄主机：`192.168.1.20`
   - （可以自定义，但必须在同一网段）

## 二、快速配置（使用脚本）

### 步骤1：在导航主机上运行

```bash
cd /home/mwk/ros/ros_ws/src/rm_behavior_tree/rm_behavior_tree/scripts
sudo ./setup_direct_ethernet.sh 192.168.1.10 192.168.1.20 eth0
```

**参数说明**：
- `192.168.1.10`：本机（导航主机）IP
- `192.168.1.20`：对方（自瞄主机）IP
- `eth0`：网卡名称（如果不确定，脚本会自动检测）

### 步骤2：在自瞄主机上运行

```bash
cd /home/mwk/ros/ros_ws/src/rm_behavior_tree/rm_behavior_tree/scripts
sudo ./setup_direct_ethernet.sh 192.168.1.20 192.168.1.10 eth0
```

### 步骤3：重新加载环境变量

**两台主机都要执行**：
```bash
source ~/.bashrc
```

### 步骤4：测试连接

**在导航主机上**：
```bash
cd /home/mwk/ros/ros_ws/src/rm_behavior_tree/rm_behavior_tree/scripts
./test_ros2_connection.sh 192.168.1.20
```

**在自瞄主机上**：
```bash
cd /home/mwk/ros/ros_ws/src/rm_behavior_tree/rm_behavior_tree/scripts
./test_ros2_connection.sh 192.168.1.10
```

## 三、手动配置（如果脚本不工作）

### 方法1：使用 nmcli（NetworkManager）

**在导航主机上**：
```bash
# 查看网卡名称
ip addr show

# 配置静态IP（假设网卡是 eth0）
sudo nmcli connection modify "Wired connection 1" \
    ipv4.addresses 192.168.1.10/24 \
    ipv4.method manual \
    ipv4.gateway 192.168.1.20
sudo nmcli connection up "Wired connection 1"
```

**在自瞄主机上**：
```bash
sudo nmcli connection modify "Wired connection 1" \
    ipv4.addresses 192.168.1.20/24 \
    ipv4.method manual \
    ipv4.gateway 192.168.1.10
sudo nmcli connection up "Wired connection 1"
```

### 方法2：使用 netplan（Ubuntu 18.04+）

**在导航主机上**：
```bash
sudo nano /etc/netplan/01-ros2-direct-eth.yaml
```

添加内容：
```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:  # 替换为你的网卡名称
      addresses:
        - 192.168.1.10/24
      gateway4: 192.168.1.20
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]
```

应用配置：
```bash
sudo netplan apply
```

**在自瞄主机上**：同样操作，IP改为 `192.168.1.20`，网关改为 `192.168.1.10`

### 配置ROS2环境变量

**两台主机都要执行**：
```bash
# 编辑 ~/.bashrc
nano ~/.bashrc

# 添加以下内容
export ROS_DOMAIN_ID=0
export ROS_LOCALHOST_ONLY=0

# 重新加载
source ~/.bashrc
```

### 配置防火墙

**两台主机都要执行**：
```bash
sudo ufw allow 7400:7500/tcp
sudo ufw allow 7400:7500/udp
```

## 四、验证配置

### 1. 检查网络连通性

```bash
# 在导航主机上
ping 192.168.1.20

# 在自瞄主机上
ping 192.168.1.10
```

如果能看到回复，说明网络配置成功。

### 2. 检查ROS2话题

**在导航主机上启动行为树**（会发布话题）：
```bash
ros2 topic list
# 应该能看到 /enemy_status 和 /autoaim_target
```

**在自瞄主机上**：
```bash
ros2 topic list
# 应该能看到相同的话题列表
```

### 3. 测试消息传输

**在导航主机上发布测试消息**：
```bash
ros2 topic pub /enemy_status sp_msgs/msg/EnemyStatusMsg \
  "{timestamp: {sec: 0, nanosec: 0}, invincible_enemy_ids: [1, 2, 3]}"
```

**在自瞄主机上监听**：
```bash
ros2 topic echo /enemy_status
```

如果能看到消息，说明通信成功！

## 五、常见问题

### Q1: ping 不通对方主机？

**检查清单**：
1. ✅ 网线是否插好（尝试重新插拔）
2. ✅ IP地址是否在同一网段（例如都是 `192.168.1.x`）
3. ✅ 子网掩码是否正确（应该是 `/24` 或 `255.255.255.0`）
4. ✅ 网卡是否启用（`ip link show` 查看状态）
5. ✅ 尝试更换网线

### Q2: ROS2话题看不到？

**检查清单**：
1. ✅ `ROS_DOMAIN_ID` 是否相同（两台主机都应该是 `0`）
2. ✅ `ROS_LOCALHOST_ONLY` 是否设置为 `0`（或未设置）
3. ✅ 防火墙是否允许ROS2端口（7400-7500）
4. ✅ 网络是否连通（先测试 ping）

### Q3: 使用 ROS_DISCOVERY_SERVER（如果自动发现失败）

**在导航主机上**：
```bash
export ROS_DISCOVERY_SERVER=192.168.1.10:11811
```

**在自瞄主机上**：
```bash
export ROS_DISCOVERY_SERVER=192.168.1.10:11811
```

### Q4: 网卡名称不确定？

```bash
# 查看所有网卡
ip addr show

# 或
ifconfig -a

# 通常是以太网卡名称是 eth0, enp0s3, enp1s0 等
```

## 六、配置完成后的使用

1. **启动导航系统**（会自动发布 `/enemy_status` 和 `/autoaim_target`）
2. **启动自瞄系统**（会自动订阅这些话题）
3. **验证通信**：使用 `ros2 topic echo` 查看消息

详细使用方法请参考：`ROS2_跨主机通信使用说明.md`
